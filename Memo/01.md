##### 1. 平滑阶梯函数
###### &emsp;使线性插值呈 S 状首尾平滑
```
smoothstep ( a , b , x ) = 3x^2 - 2x^3
```
```
根据五次多项式插值可以实现更平滑的阶梯函数
Smootherstep ( a , b , x ) = 6x^5 - 15x^4 + 10x^3
```
```
smoothstep
return ( t * t ) * 3 - ( t * t * t ) * 2 ;
smootherstep
return t * t * t * ( t * ( 6 * t - 15 ) + 10 );
```
